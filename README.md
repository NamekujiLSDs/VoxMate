# VoxMate

### Official successor port to Vanced Voxiom Client

## What is VoxMate
VoxMate is a Client of Voxiom player, by the Voxiom player, for the Voxiom player.

## Client Safety
The entire source code for VoxMate is publicly available.
We also use only open source libraries.
Check it all out if you need it.
Also, feel free to ask questions about the parts you don't understand.


## Privacy Policy
This client does NOT collect any user data or other information.


## Keybinds
|Key|Action|
|---|---|
|`F1`|Open Settings|
|`F5`|Reload Page|
|`F11`|Toggle Fullscreen|
|`F12`|Open DevTool|

## Features
- **Unlimited FPS and low-latency raw input**
- **SimpleInfo HUD** (FPS, ping, position, velocity, angles, chunks, network)
- **Custom crosshair**
- **Custom CSS loader**
- **Resource Swapper**
- **AdBlocker**
- **Userscript support** with custom settings and keybinds (see [docs/USERSCRIPT_API.md](docs/USERSCRIPT_API.md))
- **Discord Rich Presence**
- **Export and import game settings**
- **Cross-platform builds** (Windows, macOS, Linux AppImage)
- **Automatic updates**
